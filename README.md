# Object-Oriented Programming

![OOP Laboratories Banner](./cover.jpeg)

## Description
A collection of progressive Java programming assignments developed for the **Programmazione a Oggetti** (Object-Oriented Programming) course during the second semester of my third year in Computer Engineering at **Politecnico di Torino**. The repository emphasizes domain-driven class hierarchies, standard design patterns, strict encapsulation, Java Collections, and modern functional processing with the Stream API, accompanied by automated JUnit test suites.

---

## Core Competencies & Topics Covered

* **Class Hierarchies & Encapsulation:** Enforcing interface/implementation separation, abstract base classes, visibility constraints, immutability, and polymorphism.
* **Java Collections Framework:** Selecting optimal collection layouts (`List`, `Set`, `Map`, `Queue`) and defining custom ordering via `Comparable` and `Comparator`.
* **Functional Programming & Stream API:** Declarative data processing using lambda expressions, filter-map-reduce pipelines, and downstream collectors (`Collectors.groupingBy`, `partitioningBy`, `summarizingInt`).
* **Exception Management & Robustness:** Structuring checked and unchecked exception domains, fail-fast mechanisms, and defensive input parsing.
* **Object-Oriented Design Patterns:** Applying recurring creational and behavioral patterns (Factory, Strategy, Observer, Decorator).
* **Automated Testing:** Writing unit and regression test suites using JUnit to validate business constraints, edge cases, and state invariants.
